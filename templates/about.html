About the project

AI-Based Building Damage Classification

This application integrates a TensorFlow/Keras SegFormer-style image classifier with Flask, HTML, CSS, JavaScript and SQLite.

Input

A user uploads a building image in JPG, JPEG, PNG or WEBP format.

Processing

The image is resized to 224 × 224 and passed to the trained classifier.

Output

The system displays class prediction, confidence and activation heatmap.
